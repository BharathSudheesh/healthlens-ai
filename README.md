# HealthLens AI 🩺
### AI-Powered Health Risk Prediction & Blood Report Analysis

## Project Summary

HealthLens AI is an AI-powered healthcare prototype that predicts potential health risks using machine learning and analyzes uploaded blood reports to provide understandable health insights and explanations.

**Live Demo:** [Open HealthLens AI](https://healthlens-ai-nrheqybkq8fxgjwxq3ez9u.streamlit.app/)

**GitHub Repository:** [HealthLens AI](https://github.com/BharathSudheesh/healthlens-ai)

---

## How to Run and Verify the Project

Open the [public HealthLens AI URL](https://healthlens-ai-nrheqybkq8fxgjwxq3ez9u.streamlit.app/) in your browser and verify the following two scenarios.

### Scenario 1: Manual Health Data Entry

1. Enter the required health parameters.
2. Generate the health risk predictions.
3. Review the results and available explanations.
4. Download the generated report.

### Scenario 2: Blood Report Analysis

1. Open the blood report upload section.
2. Upload the provided sample blood report in PDF format.
3. Allow the application to extract and analyze the available information.
4. Review the extracted results, health insights, and available explanations.
